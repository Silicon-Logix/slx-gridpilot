# Changelog

## 0.4.2

- Limited the repository to documentation, selected screenshots, licensing and publication checks. SDK headers, runtime assets and raw verification reports are excluded.
- Kept required dependency notices and corresponding sources inside the portable Windows distribution.
- Extended header verification to documents, structured metadata and license material.
- Completed original-code copyright headers and strengthened the development repository's public-file allowlist.
- Removed personal build paths and unnecessary symbol tables from the delivered Windows binaries.
- Added automated checks for private-source exposure, credentials, headers, binary metadata and dependency notices/source archives.
- Rebuilt and revalidated the portable application and clean distribution archives.

## 0.4.1

- Made OPC UA Studio the initial workspace, with actual server, monitored-item and notification counters and a live command/feedback map.
- Added a five-step OPC UA learning tour that verifies browsing, generation, safe stop, uncertain sensor quality, acknowledgement and recovery from actual server feedback.
- Added contextual explanations for NodeId, quality, timestamps, subscriptions, deadband, methods and alarms beside the OPC UA tools.
- Clarified real protocol/control processes versus simulated plant equipment, and added a learning guide and Ctrl+0 shortcut.
- Added an attributed local Slint renderer patch to recover transient WGPU surface errors during startup, resize or display changes.

## 0.4.0

- Added sequence diagnostics, continuous numeric history, multivariable charts and a command/alarm timeline.
- Added a visual test plan editor with timed commands, feedback assertions and JSON outcome reports.
- Added dedicated watchlist monitored items, configurable sampling/publishing/deadband and server-revised interval diagnostics.
- Added typed OPC UA methods, standard alarm conditions and NodeSet2 XML export of the browsed device model.
- Added component/node navigation, flow and electrical overlays, selectable recording replay and seeking.
- Added workspace preferences, panel adjustments and keyboard shortcuts.
- Prepared source distribution with contribution/security guidance, CI checks and dependency provenance.

## 0.3.0

- Refined typography, button layout, product About, 3D ground alignment and U1/U2 identification.
- Added OPC UA browser tools, watchlists and local connection/node exports.
