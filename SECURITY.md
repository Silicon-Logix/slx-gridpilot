# Security

This release runs its OPC UA and FORTE listeners on loopback for local demonstration. OPC UA uses anonymous access and SecurityPolicy None. It has no production certificate provisioning or role-management system.

For a vulnerability report, contact Silicon LogiX through [the contact page](https://www.siliconlogix.it/contatti), identifying the product/version and requesting a private security conversation. Avoid publishing credentials or exploit details in a public issue.

Review exports before sharing: local diagnostic bundles contain application logs, endpoint state and operator commands. User workspaces are excluded from the source and portable distribution packages.
